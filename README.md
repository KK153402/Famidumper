# FamiDumper

**ROM ダンパー rev2**（ファミリーコンピュータ用カセット対応）専用の Windows アプリと、基板のファームウェアを配布するページです。

お手持ちのカセットを USB で PC につなぎ、エミュレータで遊べる `.nes` ファイルとして保存できます。

> [!NOTE]
> 本製品・本ソフトウェアは任天堂株式会社とは関係のない、個人が製作したものです。
> 「ファミリーコンピュータ」「ファミコン」は任天堂株式会社の商標です。

## 特長

- **マッパーを自動で判定**：カセットを挿して「吸い出し開始」を押すだけです。
- **ゲーム名を表示して正しく読めたか照合**：日本版約 930 件のデータベースを内蔵しています。吸い出したデータの CRC32 が登録値と完全に一致するかを確認し、保存するファイル名にもゲーム名が入ります。
- **2 回読んで照合**：カセットの接触不良による読み違いを見逃しません。
- **セーブデータの吸い出し**：電池でセーブするカセットは、`.sav` も一緒に保存します。
- **インストール不要**：.NET などのランタイムも、ドライバも要りません。

## 使い方

1. [Releases](../../releases/latest) から zip をダウンロードします。
2. zip を右クリック →「プロパティ」→「許可する」にチェック →「OK」の順に操作してから、展開します。
3. 基板を PC につなぎ、**VCC_CART の LED が消えていることを確認してから**カセットを挿します。
4. `FamiDumper.exe` を起動します。
5. ポートに「COM○（ダンパー）」が選ばれていることを確認し、「吸い出し開始」を押します。
6. 終わると保存画面が開きます。ゲーム名が入ったファイル名のまま保存できます。

### 初回起動時の警告について

コード署名をしていないため、初回起動時に **「Windows によって PC が保護されました」** と表示されます。

1. **「詳細情報」** を押します。
2. **「実行」** を押します（次回からは表示されません）。

### 結果の見方

| 照合欄の表示 | 意味 |
|---|---|
| ✔ データベースと一致 | 正しく吸い出せています |
| PRG だけ一致 | データの一部が一致しません。端子を清掃して再度試してください |
| 一致なし | データベースに未登録の版、非対応のカセット、または読み違いです |

日本版カセットのデータベース 929 件のうち、約 800 件（版違いを含む）が対応マッパーです。

| 1 | MMC1 | HVC-SxROM | 忍者龍剣伝 |
| 2 | UNROM | HVC-UNROM / UOROM | ドラゴンクエストII 悪霊の神々 |
| 3 | CNROM | HVC-CNROM | ソロモンの鍵 |

| マッパー | 名称 | 主なメーカー・基板 |
|---|---|---|
| 1（PRG 512 KB） | MMC1（SUROM / SXROM） | ドラゴンクエストIV、ファイナルファンタジーⅠ・Ⅱ など |
| 18 | Jaleco SS88006 | ジャレコ |

| 69 | Sunsoft FME-7 | サンソフト |
| 87 | Jaleco / Konami 87 | ジャレコ・コナミ |

実機で吸い出せた（またはうまくいかなかった）タイトルがあれば、[Issues](../../issues) で教えていただけると助かります。

### 現在未対応（今後のアップデートで対応予定）

- MMC5、Namco 163 以外のナムコ独自マッパーの一部、バンダイ FCG（16 / 159）、Taito X1-005（80）、VRC6 / VRC7 など
- コピー防止付きの CNROM（185）

### 本製品では対応できないもの

- ディスクシステム（磁気ディスクのため、別の装置が必要です）
- 海外版（NES）カセット（端子の形状が違うため挿せません）

### セーブデータ

| 項目 | 内容 |
|---|---|
| 対象 | マッパー 1（MMC1）・4（MMC3）で、セーブ容量 8 KB のカセット |
| 読み方 | セーブ領域を書き込み禁止にした状態で読むので、吸い出しでセーブデータが変わることはありません |
| 確認状況 | MMC3 は実機で確認済みです。**MMC1 は試験装置での確認のみで、実機では未確認です** |
| 未対応 | カセットへの書き戻し、セーブ容量 16 KB 以上のカセット |

## ファームウェアの更新

アプリが「ファームが古いです」と表示したときに行います。作業の前に、カセットは抜いておいてください。

1. [Releases](../../releases/latest) から `firmware.uf2` をダウンロードします。
2. 基板の **BOOT ボタンを押したまま RUN ボタンを押して離し、そのあと BOOT ボタンを離します**。PC に `RPI-RP2` ドライブが現れます。
3. `firmware.uf2` を `RPI-RP2` ドライブにドラッグ＆ドロップします。
4. ドライブが自動で消えれば完了です。

## 困ったときは

| 症状 | 対処 |
|---|---|
| ポートに「（ダンパー）」が出ない | データ通信対応のケーブルで PC に直接つなぎ、「更新」を押す |
| 「他のアプリが使用中です」 | シリアル通信を使う他のアプリ（Arduino IDE など）を閉じる |
| 「2回の読み出しが一致しません」 | カセットの端子を清掃して再度試す |
| 「マッパーを判定できませんでした」 | 非対応のマッパーの可能性があります。対応表を確認し、対応していればマッパーを手動で選ぶ |
| 「ファームが古いです」 | [ファームウェアを更新](#ファームウェアの更新)する |

不具合のご報告は、アプリの「ファイル → ログを保存」で保存したログを添えて、BOOTH のメッセージまたは [Issues](../../issues) からお願いします。
